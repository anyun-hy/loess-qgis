📊 数据流总结
UI 配置 ──────────────────────────────────────────────────────────────────────
  脚本路径 / 输出路径 / Tile 尺寸 / Overlap / 跳过已确认

切片 ─────────────────────────────────────────────────────────────────────────
  extent + tile_width × tile_height + overlap
    → generate_grid() → tile 网格 (col, row, bounds, pixel_w, pixel_h)
    → extract_tile()  → output/cache/<run_id>/tile_cache/tile_{row}_{col}.tif

Phase 1 — 语义分割 ────────────────────────────────────────────────────────
  tile.tif → run_semantic.sh → predict_semantic.py
    → torch.jit.load(weight) → model(tile_tensor) → argmax → mask.tif + conf.tif

Phase 2 — 镶嵌 + 矢量化 ──────────────────────────────────────────────────
  masks/*.tif → run_mosaic.sh   → semantic_mask_mosaic.tif
  mosaic.tif → run_polygonize.sh → polygonize_mosaic.py → semantic_polygons.gpkg

Phase 3 — 差分过滤 ────────────────────────────────────────────────────────
  semantic_polygons − accepted_labels → difference_filter.py → diff_candidates.gpkg

Phase 4 — SAM3 修边 ────────────────────────────────────────────────────────
  raster + diff_candidates → run_sam3.sh → sam3_refine.py
    → SAM 点提示(centroid) → mask → contour → refined polygon
    → 失败时保留原始几何 → sam_refined_polygons.gpkg

审查 + 入库 ────────────────────────────────────────────────────────────────
  用户选择候选面 → 接受 → accepted_writer.py → accepted_labels.gpkg
  下次运行时: skip_accepted → tile_is_fully_accepted() → 跳过已确认区域
